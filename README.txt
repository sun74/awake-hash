Awake#
=======

Τι κάνει
- Εναλλάσσει (με μπαταρία) τη ρύθμιση «Όταν κλείνω το καπάκι»
  μεταξύ «Καμία ενέργεια» και «Αδρανοποίηση».
- ΔΕΝ είναι το PowerToys Awake και δεν κρατάει τον PC ξύπνιο.

Εγκατάσταση σε άλλον υπολογιστή
1. Αντίγραψε όλο τον φάκελο Awake# (ή άνοιξε το zip).
2. Τρέξε Install.bat
3. Επίλεξε αν θέλεις έναρξη με τα Windows.

Χρήση
- Αριστερό κλικ στο tray icon: toggle
- Δεξί κλικ: Καμία ενέργεια / Αδρανοποίηση / Έναρξη με τα Windows / Έξοδος
- Ctrl+Alt+L: γρήγορο toggle (μετά την εγκατάσταση)

Αρχεία
- LidTray.ps1          → tray εφαρμογή
- LidToggle.Lib.ps1    → λογική powercfg
- Start-LidTray.vbs    → εκκίνηση χωρίς μαύρο παράθυρο
- AwakeHash.ico        → εικονίδιο
- Install.bat          → εγκατάσταση shortcuts
